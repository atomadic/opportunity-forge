# OpportunityForge – Your Zero-Cost AI Digital Income Factory

Daily 3 premium AI+Programming products auto-generated and zipped for Payhip.

**How it works**
- GitHub Actions runs every day at 9 AM UTC
- Products land in `/products` and `/output`
- Download ZIPs → upload to Payhip (5 min/week)

First run: Go to Actions tab → click "Daily OpportunityForge" → "Run workflow"
